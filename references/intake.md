# Intake by source type

Use only the parts matching the actual input. Save originals and a bounded extraction inventory in the task's working directory.

## URL or HTML

- Save the page source and inspect the rendered article. Dynamic charts, lazy images, tabs, footnotes, and captions may be absent from plain-text extraction; inspect their data/scripts or rendered states.
- Distinguish article content from site navigation, ads, comments, and controls. If the user asks for the entire page, inventory those too. Record exact URLs for downloaded visual assets and a retrieval date.

## PDF, document, slides, spreadsheet

- Inspect every page/sheet/slide in order, including headers, footnotes, appendices, tables, and embedded images. Use the specialized installed format skill when it materially improves extraction or visual QA.
- Preserve reading order and page/slide/sheet locators. Scientific equations, multi-panel figures, merged cells, and chart axes require visual inspection; text extraction alone is not sufficient.

## Image or scanned pages

- Inspect the image at readable resolution; OCR all visible text and verify critical labels/numbers against pixels. Record diagram relationships, not only extracted strings.
- If the image is too small or obscured, request a better copy or mark the affected area unresolved.

## Audio or video

- Obtain a full transcript with timestamps and inspect the media for on-screen text, slides, charts, and meaningful visual events. Keep speech and screen content as separate source items.
- If the source is inaccessible, only a poster/thumbnail is available, or transcription is unavailable, report that scope. A poster cannot stand in for a complete video translation.
- For long media, divide by timestamps, retaining continuity and coverage. Preserve speaker changes and meaningful pauses when they affect interpretation.

## Mixed or unusual formats

- Identify each embedded modality and inventory it separately. Use the available tools that can actually inspect it. Do not claim coverage of a modality the environment cannot read.
